# 垫高 — 从 STL 反推的二维底图

## 结论

| 项目 | 值 |
|---|---|
| `垫高.stl` / `垫高 右边.stl` | **同一个零件的左右镜像件**（Y 轴镜像，X/Z 尺寸完全相同） |
| 主轮廓 | 8 边形，沿 Y **拉伸 30 mm** |
| 主轮廓面积 | 4914.83 mm² |
| 外形包围盒 | 50.07 × 30 × 147.65 mm |
| 内部孔 | **没有孔**（STL 共 44 个三角面，水密，无圆柱特征） |
| 底部凸台 | 48.7185 × 4 mm 截面，沿 Y 只有 **6.5 mm** 宽（定位凸筋） |

## 设计意图尺寸（比坐标更好用）

角度 **13°**（斜面相对竖直线倾斜 13°，即相对 +X 为 103°）

```
A→B  48.7185   水平（= 50·cos13°），B 在 C 正下方
B→C  94.9293   竖直
C→D  50.0000   与竖直成 13°
D→E   6.0000   垂直于 CD
E→F  44.0000   平行于 CD
F→G  44.0000   垂直于 CD
G→H   6.0000   平行于 CD
H→A  83.6817   竖直
```

即：一个 **壁厚 6 mm、外框 50×50、内腔 44×44 的 "[" 形托架，整体倾斜 13°**，
下面接一个竖直/水平的世界坐标底座块。CD ∥ EF ∥ GH（都在 13°方向），DE ∥ FG。

## 厚度方向（STL 的 Y）

- 主体：Y = -165 → -135，共 **30 mm**
- 底部凸筋：Y = -158.5 → -152，**宽 6.5 mm，深 4 mm**
  （换算：离 y=-135 那一面 17.0 mm 处开始，18.5 mm 处结束）

## 文件

| 文件 | 用途 |
|---|---|
| `dian_gao_profile.dxf` | 主轮廓 8 边形（闭合多段线，mm），插入 Fusion 后拉伸 30 mm |
| `dian_gao_rib.dxf` | 底部凸筋截面 48.7185×4 矩形，单独拉伸 6.5 mm |
| `dian_gao_profile.svg` | 带尺寸标注的查看图 |
| `make_profile.py` | 生成上面三个文件的脚本（改参数可重出） |

## Fusion 里怎么用

1. **插入 DXF**：新建草图（选 XZ 平面 / 或你要的方向平面）→ `插入 > 插入 DXF/DWG`
   → 选 `dian_gao_profile.dxf` → 单位选 **毫米** → 定位到原点。
2. 选中轮廓 → **拉伸 30 mm**（单侧或对称 15 mm，看你放哪）。
3. 新草图用 `dian_gao_rib.dxf` → 拉伸 **6.5 mm**，方向与主体垂直，
   起始面相对本体一侧留 6.5 mm（见上面的凸筋位置）→ 合并。
4. 两个件是镜像关系：做完一个，用 **镜像**（对 YZ 平面 / 中间平面）出另一个。

## 校验

DXF 顶点与 STL 顶点逐点比对，最大偏差 **0.0003 mm**；
另外对 STL 做了 3000 点射线穿越测试，实物区域与 8 边形轮廓完全一致
（唯一差异就是底部那条 4 mm 凸筋，单独出图了）。
