# DummyArm M0 · 规格冻结文档（成稿 v1.0, 2026-09-09）

> 目标：把本会话所有「实测/图纸/固件」真值收敛成正式规格，作为 URDF/ros2_control/
> 文档/面试展示的统一依据。凡与旧资料冲突处，以本文为准。

## 1. 机械臂本体

- 构型：Dummy-Robot V2 国产化复刻（auk/晓文链，CNC 铝件「视频款/改版」结构件）
- 自由度：6（全旋转）
- 主控：STM32F405 REF 板（USB-CDC `/dev/ttyACM1` @115200，ASCII 协议）
- 末端：空谐波减速器壳（无夹爪）；J6 将驱动自研「套果-旋切」末端执行器
- 用户实测：J1 底座开孔高 92.6mm（= 图纸 55 基座 + 37.5 J1件）

## 3. 图纸真值（几何，mm）

- L_BASE=92.5(实测92.6)、D_BASE=35、L_ARM=146、D_ELBOW=52(图纸50)、L_FA=115、
  J5B 大孔 Φ31.05、J6 轴 Φ8.95/减速器 Φ26.10
- 来源：改版工程图逐张标注 + STEP 轴孔互证
- 与固件 DH(0.109/…)差异：固件 L_BASE 用原版值(近似), 物理=92.5 → 模型/固件世界差 ~16mm 属预期

## 4. 坐标/角度约定

- 世界：桌面=z0, X=臂前, Z=上, Y=侧（右手）
- 模型链(FW→模型)：`q_model = SIGNS·(q_fw + TH_HOME)`, SIGNS=[+,-,-,+,+,+], TH=[0,-90,90,0,0,0]
  （Kabsch 双姿态残差 0.04mm 验）
- p_fw ≈ p_model + (60.85, 0, 171.14) mm（两世界关系, 诊断用）
- 命名：关节 Joint1..6, 链 link_1..6/tool0, 机器人 dummyarm

## 5. 控制链（已实测）

- 桥接(管理): dummyarm_bridge/dummyarm_system — 服务 start/disable/stop/home/reset
- ros2_control: dummyarm_hardware (C++ SystemInterface) — /joint_states 实测
  [0, 163, −270, 0, 0, 0] 与预期一致
- 启动不使能、!STOP 急停、非测试停 REST(0,-73,180)/失能
