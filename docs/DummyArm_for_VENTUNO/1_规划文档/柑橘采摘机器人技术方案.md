  2. **训练:** 利用M4 Max的GPU加速（PyTorch MPS后端）进行训练。  
  3. **模型转换:** FV04的高通芯片需要使用 **SNPE (Snapdragon Neural Processing Engine)** 或 **QNN SDK** 才能发挥算力。你需要将PyTorch模型导出为ONNX，再转换为DLC或QNN格式。如果这对初学者太难，可以暂时使用**TFLite** (Android支持好)，虽然牺牲一些速度，但部署更简单。

  4. **关键一步:** 对坐标进行滤波（卡尔曼滤波或简单的滑动平均），因为树叶遮挡会导致坐标跳动。

#### **C. 末端执行器与作业逻辑 (End-Effector)**

**现状分析：** 侧边开孔、双层锥型旋转剪切。 **控制逻辑:**
