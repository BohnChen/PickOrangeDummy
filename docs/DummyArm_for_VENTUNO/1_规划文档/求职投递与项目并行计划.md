# 求职投递与项目并行计划（第一版）

更新时间：2026-07-31

## 一、当前定位

### 对外求职定位

**C++ / Linux 机器人软件实习生｜ROS2、真机集成与机械臂方向**

不把自己包装成纯算法、底层驱动或成熟嵌入式工程师。核心卖点是：

- 有真实的商业 C++ 软件开发经历；
- 熟悉 Linux 系统编程与网络编程，有完整项目源码；
- 使用过 ROS2 的话题、服务、Action、Launch、参数、URDF、Gazebo 和 RViz2；
- 做过机器人 SDK 二次开发和真机功能验证；
- 拥有可长期使用的高精度机械臂和舵机机械臂，可以持续产出真机项目；
- 有农业采摘场景、RGB-D 数据集、发明专利与末端执行器研究积累。

### 岗位优先级

1. 机器人软件开发实习生、ROS2 开发实习生；
2. C++ 软件开发实习生，机器人、智能硬件、AIoT 方向；
3. 嵌入式 Linux 应用软件实习生；
4. 机器人系统集成、平台软件、自动化测试与开发工具岗位；
5. 大公司通用 C++ / Linux 软件开发实习岗位。

暂不主投：SLAM 算法、视觉算法、运动控制算法、Linux 内核驱动、纯 MCU 固件、大模型训练。

## 二、岗位调研结论

## 三、双线推进原则

### 投递线

不等待项目完成。简历达到可投标准后，48 小时内启动第一批投递。

- 每周新增 15-25 个有效岗位；
- 冲刺岗位约 20%，重点匹配岗位约 50%，扩展岗位约 30%；
- 同一家公司优先投 1-2 个最匹配岗位，避免无差别海投；
- 每个岗位保存完整 JD，记录使用的简历版本和投递渠道；
- 每周根据回复率、笔试率和面试反馈调整关键词与岗位范围。

### 项目线

主项目不再另起炉灶，直接把现有高精度机械臂做成可展示、可测试、可解释的 ROS2 工程。

项目暂定名：**ROS2 机械臂任务执行与安全监控系统**。

目标不是展示“机械臂能动”，而是证明能够把一个真实设备接入可靠的软件系统。

## 四、主项目设计

### 第一阶段：真机接入与统一接口

- 封装机械臂现有坐标控制接口，隔离厂商 API；
- 编写 ROS2 驱动/适配节点；
- 通过 Topic 发布状态，通过 Service 管理复位等即时操作；
- 通过 Action 实现可反馈、可取消、可超时的运动任务；
- 补全 URDF、TF、robot_state_publisher 和 RViz2 可视化；
- 建立仿真与真机尽量一致的启动方式和参数配置。

### 第二阶段：可靠性与工程质量

- 增加工作空间限制、速度限制、超时和急停逻辑；
- 增加断连检测、错误码转换、自动恢复或安全退出；
- 使用状态机或行为树组织任务流程；
- 增加日志、rosbag 复现和关键指标统计；
- 使用 gTest、pytest 或 launch_testing 编写核心测试；
- 增加 Docker 环境、持续集成和一键启动脚本。

### 第三阶段：场景能力

- 接入 RGB-D 相机或已有数据；
- 完成相机坐标系到机械臂基座坐标系的 TF 变换；
- 实现目标点输入、抓取任务编排和失败恢复；
- 视时间再加入视觉检测，不把训练模型作为第一阶段前置条件。

### 最终证据

- 一个结构清晰、可以公开的 GitHub 仓库；
- 一张系统架构图和一张 ROS2 节点图；
- 60-90 秒真机演示视频；
- README 中给出环境、启动方法、接口、异常处理和测试结果；
- 至少记录任务成功率、控制指令延迟、超时恢复或连续运行时长中的两项。

## 五、面试准备线

在拿到实习前，每天安排约 3 小时；开始实习后压缩为工作日晚间 1-1.5 小时。

- C++：RAII、对象生命周期、智能指针、STL、移动语义、虚函数、多线程与并发；
- Linux：进程线程、IPC、虚拟内存、文件系统、I/O、多路复用、TCP；
- 算法题：数组、链表、哈希、二叉树、二分、滑动窗口、基础动态规划；
- 项目表达：文件系统项目、维宏工作、ROS2 机械臂项目各准备 3 分钟和 10 分钟版本；
- 华为等大厂：单独加强在线机考速度和边界处理。

## 六、启动节奏

### 第 1-2 天

- 完成经历事实盘点；
- 生成机器人/ROS2 版简历；
- 生成大公司 C++/Linux 版简历；
- 整理 GitHub 主页和已有项目仓库；
- 建立岗位投递跟踪表。

### 第 3-4 天

- 投递首批 8-12 个岗位；
- 优先投海康机器人、宇树相关入口、华为及高匹配机器人公司；
- 启动机械臂 ROS2 仓库、URDF 和驱动适配层；
- 开始 C++ 与 Linux 面试复习。

### 第 5-7 天

- 累计投递 15-20 个有效岗位；
- 完成真机基础运动的 ROS2 Action 闭环；
- 录制第一版演示；
- 根据首轮反馈修改简历关键词和岗位层级。

### 第 2 周

- 主项目补异常处理、状态机和测试；
- 累计投递 30-40 个有效岗位；
- 开始模拟面试和项目深挖；
- 若回复率低于 10%，检查简历、岗位匹配和投递渠道；
- 若有笔试但通过率低，优先增加算法题和基础知识训练。
