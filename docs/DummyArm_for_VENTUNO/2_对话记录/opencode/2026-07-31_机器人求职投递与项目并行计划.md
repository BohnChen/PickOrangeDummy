| **帧解析状态机** | `!START`/`>J1..J6`/`@X,Y,Z`/`#GETJPOS` 按 ASCII 协议解析，状态机实现（WAIT_HEADER→LEN→PAYLOAD→CHECK） | 状态机设计、协议解析 |
| **校验** | 每帧加校验字节（累加和或 CRC-8） | 链路可靠性 |
| **应答与重试** | 发命令等 ACK，超时重发 N 次，记日志 | 容错设计 |
| **非阻塞 IO** | 用 termios 设置 RAW 模式 + VTIME/VMIN，或独立收发线程 | 嵌入式 Linux 串口编程实战 |

- 用**硬件抽象接口**（HAL 类）设计，mock 版和真机版可切换——这直接证明你的架构能力
