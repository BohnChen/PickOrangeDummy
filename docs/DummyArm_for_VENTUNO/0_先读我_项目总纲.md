## 2. 这个项目是什么（一句话版）

把一台复刻的 **Dummy 超紧凑六轴机械臂**（基于 peng-zhihui 开源的 Dummy-Robot）建设成**可复用的 ROS2 + RGB-D 视觉抓取 / 操作 / 学习实验平台**；远期服务于主人毕业课题——「面向低位果实采摘的自主移动机器人」（六轴机械臂 + RGB-D 相机 + 移动底盘）。

项目同时有两条并行主线：

1. **技术主线（第一版验收）**：桌面目标「检测 → 求位姿 → 规划 → 抓取 → 放到指定位置」的完整经典闭环（详见 `1_规划文档/DummyArm-ROS2-Grasp-项目蓝图.md`）。
2. **求职展示线**：把该机械臂做成可展示、可测试、可解释的工程「ROS2 机械臂任务执行与安全监控系统」，作为投递机器人/ROS2 岗位的项目证据（详见 `1_规划文档/求职投递与项目并行计划.md`）。

## 3. 核心技术基线（蓝图要点摘要）

- 机械臂：6 关节全为旋转关节（Pieper 判据构型）；电机 + 减速器 + 绝对值编码器；ref-controller（GD32）负责底层控制。
- 分层职责（硬实时下沉到 MCU，不放进 Linux）：
  - MCU（GD32）：电机闭环、编码器、限位、急停、看门狗、故障码
  - `ros2_control`：机械臂以 `SystemInterface` 暴露，统一硬件抽象
  - MoveIt 2：IK、碰撞、规划、轨迹执行
  - 感知：RGB-D 同步、检测/分割、目标 3D 位姿（第一版相机为 eye-to-hand 外部固定支架）
  - 任务层：pick/place 状态机或行为树、超时/重试/恢复
  - 学习层（后期）：模仿学习 / RL，只输出受限的 TCP 增量或技能参数，不得绕过安全层直控电机
- 接口约定：优先复用标准话题/接口；自定义高层接口仅 `PlanGrasp.action`、`PickPlace.action` 两个；统一 REP-103（米、弧度、右手系），TF 树 `world → base_link → … → tool0 → tcp`，`base_link → camera_link`。
- 工作空间结构（规划包名）：`dummyarm_ros2_grasp/src/` 下含 description / hardware / bringup / moveit_config / interfaces / perception / grasp_planner / task / calibration / sim / data / learning / w4d_integration。
- 仿真栈：主线 Gazebo Fortress + `ros_gz`/`gz_ros2_control`；早期用 MoveIt 2 FakeSystem 验证 URDF/规划组；学习后期才上 Isaac Lab / MuJoCo；URDF/Xacro 是单一模型源，不要同时维护多套资产。
- 四层仿真成熟度：运动学（FakeSystem）→ 动力学（Gazebo）→ 感知 → 学习。
- 第一版 ROS 图：单机运行全部真机节点，GD32 为非 ROS 实时从控，开发机经局域网看 RViz/日志。

> 以上是 2026-07-29 规划的基线。请结合现场实物与文件 `1_规划文档/DummyArm-ROS2-Grasp-项目蓝图.md`（407 行，最完整）一起判断取舍。
