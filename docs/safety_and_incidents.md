# 机械臂事故史与安全约束（必读）

> 本文记录这台 Dummy 机械臂的损坏历史、成因与由此确立的硬性操作约束。
> 任何新的控制代码/会话/操作者都必须先读本文。

## 1. 历史事故（主人陈述）

- 刚组装完成时，**J3 关节曾超出限位**，导致 **J4 与 J3 连接处崩坏**（结构损坏）。
- 主人随后**重新设置了机械臂的起始状态（标定）**，此后运行正常。
- 因此：本机软限位与标定零位是「校准后安全」的边界，**不得擅自扩大**；
  尤其 J3 的低位侧是历史损坏区。
- **装配教训（主人总结）**：新装/重装机械臂后，必须先对**每个关节逐一定位
  （setposition / 设起始零位）**、确认限位方向正确后再开始任何运动测试；
  不可直接跑整臂动作。

## 2. 2026-09-08 误命令事故（本会话）

- 原因：行为探针脚本参数顺序写错，误发大角度目标（J1→-74°、J2→0°、J3→90°），
  机械臂在低速下持续运动约 30~60s。
- 处置：`!STOP` 急停 → 冻结于 (J1=-43.8, J2=-29.8, J3=126.7) → 低速 (speed 3) 回 REST → 失能。
- 无结构损坏；教训：**任何非例行命令必须先经 `_check_limits` + 人眼复核格式**。

## 3. 硬性操作约束

1. J3 角度范围严格 **[35°, 180°]**（固件软限位=安全底线，禁止以任何方式绕过）
2. 常规动作 J3 建议留在 **[40°, 178°]** 内部（余量带）；接近边界必须主人确认
3. 多轴同时大角度运动：先给主人看目标数组，确认后才发
4. 所有运动命令必须经 `dummyarm_link` 限位检查（`check_limits=True`）
5. 意外行为第一反应：`!STOP`（急停锁位+清FIFO+失能），再诊断
6. 非测试时段：机械臂失能 + 停在 REST (0,-73,180,0,0,0)
7. 使能时人不在旁/不在看：不允许
8. 若需重新标定：按固件 `!CALIBRATION` 流程（L 位手动摆姿 → 回中 → 重启），
   期间 J3 手动摆动须极其缓慢并避开 35° 以下
9. **动作前先回 `!HOME`（7 字姿态 (0,0,90,0,0,0)），再开始执行动作**；动作结束回 REST + 失能
   （主人规定，2026-09-10；`dummyarm home` = 低速 10、阻塞到完成）

> 注（2026-09-10）：本节角度均为**物理/固件角**（安全底线以此为准）。模型角为
> `q_model = SIGNS·(q_fw + TH_HOME)`（TH=[0,−90,0,0,0,0]）：J3 物理 [35°,180°] = 模型 [−180°,−35°]，
> J2 物理 [−73°,90°] = 模型 [0°,163°]；REST 模型值 (0,163,−180,0,0,0)。

## 5. 末端执行器相关事故（2026-11-01，两次）

### 5.1 事故A：J2 收缩 + J5 翻转，末端扫向车架

用"只约束位置"的 IK（`solve_exact_tool0_ik`）横移 10cm 时，
IK 为了让 TCP 到位把 J2 从直立位收缩、并把 J5 从 −74° 翻到 +0.18°，
153mm 长、最大外廓 172mm 的锥形末端整体扫过，圆形开口转向车架。
人工断电止损，未损坏。

**对策**（已实现）：
- `scripts/arm_safety.py`：末端解析体积 + 车体包围盒 + 24 步 slerp 扫掠检查
- 判据是"侵入深度不得比起点更深"（允许逃开，禁止靠近）
- 所有定位改用**保持当前姿态**的位姿 IK（`solve_pose_ik`，约束工具 Z 轴）

### 5.2 事故B：用 J6 做滚转，等于执行了一次剪切

为把出料口从"朝天"转到"朝下"，下发 6 步 ×30° 的滚转。
IK 每步从零重解，跳到等价解分支：J4 保持不动，**全部滚转压在 J6 上**
（−0.6° → −196°）。而 J6 是刀片驱动轴，于是刀片被一路转到底 = 剪切。

**根因**：J6 同时承担"绕锥罩轴线滚转"与"刀片开合"，用 IK 动 J6 必然切果。

**对策（三道闸，已实现）**：
1. 规划层：`check_pose` / `arm_goto_xyz` 下发前强制 `fw[5] = 实测 J6`
2. 校验层：以"丢弃 J6 后的真实姿态"评估出料口偏离正下方角度，> 50° 拒绝
3. 通信层：`RefSerial.write` 若 `'>'` 指令中 J6 变化 > 0.3° 直接抛
   `J6Violation`，**指令根本发不出去**（`j6_locked=True` 默认）

**唯一豁免**：`do_cut()`，先校验 `|ΔJ6| ≤ 90°`，临时解锁，
`try/finally` 里无论成败立即重新上锁并以实测值为新基准。

### 5.3 末端执行器几何（STL 实测，`02_opResource/models/`）

| 件 | STL X | STL Y | STL Z |
|---|---|---|---|
| 法兰 | ±17.5 | ±30.5 | −8 → 0 |
| 外壳 | ±86.0 | −128 → 88 | −36 → 117 |
| 内层转子 | ±72.1 | ±73.0 | −10.4 → 123 |
| 上刀片 | −9.3 → 103.5 | ±102 | 123 → 128 |
| 下刀片 | −112.5 → 9.3 | ±107 | 118 → 123 |

- **tool0（法兰安装面 Z=−8）→ 罩口平面（Z=117）= 125mm**
- tool0 → 刀片外沿 = 136mm；罩口内径 ≈ Ø120；最大外廓 ≈ 172mm
- **出料口法向 = −Y_tool**（外壳 Y 多出 −128 那一片是出料槽侧壁）
- 出料口朝下 ⇔ `Y_tool.z > 0`；`port_down_deg()==0` 为正中朝下

### 5.4 姿态纪律

- 锥罩瞄准用 **J5 俯仰**，允许大幅摆动
- **不允许**用 J6 做滚转（会切果）
- 滚转只能由 J1~J5 的组合产生；规划时若出料口偏天 > 50° 该解作废
